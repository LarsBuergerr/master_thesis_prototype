

### Auffindbarkeit

| Index                                                | Key                      | Beschreibung                                                                                                                                    |
| ---------------------------------------------------- | ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Schlagwörter angegeben                               | `dcat:keyword`           | Sind Keywords als `dcat:keyword` gesetzt. Ist die Anzahl der Keywords k  2 < k < 6                                                              |
| Theme angegeben                                      | `dcat:theme`             | Ist `dcat:theme` gesetzt und nicht leer                                                                                                         |
| Theme aus kontrolliertem Vokabular                   | `dcat:theme`             | Ist `dcat:theme` aus einem der folgenden kontrollierten Vokabular<br>- http://publications.europa.eu/resource/authority/data-theme/             |
| Räumliche Suchangabe angegeben                       | `dct:spatial`            | Ist `dct:spatial` gesetzt und nicht leer                                                                                                        |
| Räumliche Suchangabe aus kontrolliertem Vokabular    | `dct:spatial`            | Ist `dct:spatial` aus einem der folgenden kontrollierten Vokabular<br>- https://www.dcat-ap.de/def/politicalGeocoding/                          |
| Zeitliche Abdeckung angegeben                        | `dct:temporal`           | Ist `dct:temporal` durch  `dcat:startDate` oder `dcat:endDate` gesetzt                                                                          |
| Änderungsdatum angegeben                             | `dcat:modified`          | Ist `dcat:modified` mit korrekter Syntax gesetzt.                                                                                               |
| Aktualisierungsfrequenz aus kontrolliertem Vokabular | `dct:accrualPeriodicity` | Ist `dct:accrualPeriodicity` angegeben                                                                                                          |
| Aktualisierungsfreqenz aus kontrolliertem Vokabular  | `dct:accrualPeriodicity` | Ist `dct:accrualPeriodicity` aus einem der folgenden kontrollierten Vokabular:<br>- http://publications.europa.eu/resource/authority/frequency/ |
| Angemessene Menge an Keywords angegeben              | `dct:keyword`            | Keyword Anzahl zwischen 5 - 10                                                                                                                  |

### Zugänglichkeit

| Index                                            | Key                                                                       | Beschreibung                                                                                                                                                                                                                                                                                                                             |
| ------------------------------------------------ | ------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Access-URL technisch erreichbar                  | `dcat:accessURL`                                                          | AccessURL gibt korrekten Response Code zurück                                                                                                                                                                                                                                                                                            |
| Download-URL angegeben                           | `dcat:downloadURL`                                                        | Ist `dcat:downloadURL` gesetzt, nicht leer und ein korrekter Link                                                                                                                                                                                                                                                                        |
| Download-URL technisch erreichbar                | `dcat:downloadURL`                                                        | `dcat:downloadURL` gibt korrekten Response Code zurück                                                                                                                                                                                                                                                                                   |
| Format angegeben                                 | `dct:format`                                                              | ist `dct:format` gesetzt und nicht leer                                                                                                                                                                                                                                                                                                  |
| Format aus kontrolliertem Vokabular              | `dct:format`                                                              | Ist `dct:format` aus einem der folgenden kontrollierten Vokabluar:<br>- http://publications.europa.eu/resource/authority/file-type/                                                                                                                                                                                                      |
| Medientyp angegeben                              | `dcat:mediaType`                                                          | Ist `dct:mediaType` gesetzt und nicht leer                                                                                                                                                                                                                                                                                               |
| Medientyp aus kontrolliertem Vokabluar           | `dcat:mediaType`                                                          | Ist `dct:mediaType` aus dem folgenden kontrollierten Vokabluar:<br>- https://www.iana.org/assignments/media-types/media-types.xhtml                                                                                                                                                                                                      |
| Maschinenlesbares Format                         | `dct:format`<br>`dct:mediaType`<br>`dcat:downloadURL`<br>`dcat:accessURL` | Mindestens eine Distribution hat ein maschinenlesbares Format.<br>In der Reihenfolge wie unten wird die Qualität absteigend bewerten:<br>CSV, JSON, GEOJSON, RML<br>XLSX<br>HTML<br>PDF<br>IMAGE                                                                                                                                         |
| Zugriff zur Ressource                            | `dcat:downloadURL`<br>`dcat:accessURL`                                    | Es werden abnehmend weniger Punkte vergeben abhängig vom Zugriff zur Ressource<br><br>1. Hat mindestens eine Distribution ein maschinenlesbares Format mit einem direkten Download der Ressource<br>2. Hat nicht einen direkten Download zur Ressource aber ein Download zur kompressed Ressource<br>3. Kein direkter Download vorhanden |
| Formatkongruenz zwischen Metadaten und Ressource | `dcat:format`<br>`dcat:mediaType`<br>`dcat:downloadURL`                   | Passt das Format, MediaType zur eigentlich hinterlegten Ressource                                                                                                                                                                                                                                                                        |
| Dateigrößte plausibel                            | `dcat:byteSize`<br>`dcat:downloadURL`                                     | Passt die byteSize angabe zur Download-Größe                                                                                                                                                                                                                                                                                             |
